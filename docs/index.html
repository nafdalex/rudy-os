WHAT HAPPENS WHEN YOU HIRE

Hire, hand over the job, watch the floor clock in. Three moves, then the office runs itself.

01

Hire an agent

Contract, face and name, workspace, engine. Pick from the cast or write your own role. Every hire comes loaded with skills, memory, a mailbox and a desk.

02

Give Rudy the job

Talk to Rudy in his terminal, in plain words. He writes the cards, assigns them and routes the work. Ask him to hire and he staffs the floor himself.

03

The floor clocks in

Statuses flip, the board fills, cards land on done with their results attached. Every agent keeps a record you can open later.

THE QUESTIONS EVERYONE ASKS

Does my code or data leave my machine?

No. Agents run as processes on your Mac, in your folders, with your keys. There is no server and no account. The only network traffic is what your agents themselves do, plus a read-only check for updates.

Will this eat my Claude subscription limits?

It runs on the plans you already have, so yes, working agents use them, exactly as if you ran the CLI yourself. You decide how much: per-agent token caps, a floor-wide budget, and a pause button for the whole office. Nothing is marked up and nothing is metered by us.

Can agents step on each other's work?

Each hire can get its own git branch in an isolated worktree, so two agents never type over each other. Rudy integrates the branches and runs the final check before anything merges.

What stops an agent from going rogue?

A circuit breaker watches every agent and steps in when one loops or overspends: steer first, then constrain, then stop. Destructive moves can be gated behind your click, and spend caps are hard limits, not suggestions.

Do I have to babysit it?

No. Anything that truly needs you lands on the NEEDS YOU board as a question, and a desktop toast tells you who finished what. Everything else keeps moving while the app sits in the background.

How is this different from five terminal tabs?

Tabs do not talk to each other. Here every agent has memory that survives the session, a mailbox for handoffs, a shared task board, and a boss who routes work and escalates only what matters. It is coordination, not just multiplexing.

What do I need installed?

A Mac and at least one CLI coding agent you already use, for example Claude Code. Rudy OS finds it and runs it. More engines can be added anytime in settings.

Is it Mac only?

Today, yes: one universal build for Apple Silicon and Intel. Windows and Linux builds are planned, and the build configs already sit in the repo.

Is it really free?

Yes. Free and open source under MIT, not a trial and not a tier. You already pay for the agents; the office costs nothing.
