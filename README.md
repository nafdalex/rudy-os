# Rudy OS

**Free, open source agent office.** It wraps the CLI coding agent you already
use (Claude Code, Codex, Gemini CLI, Grok, Qwen, Copilot CLI, Cursor and more)
and runs a whole office of agents on your own machine.

**[rudydoes.com](https://rudydoes.com)** · [Download the latest release](https://github.com/rudydoes/rudy-os/releases/latest)

</div>

## What lives here

This repository is the public home of Rudy OS: the website served at
[rudydoes.com](https://rudydoes.com), the
[releases](https://github.com/rudydoes/rudy-os/releases) you download, the
auto update feed the app reads, and the
[issue tracker](https://github.com/rudydoes/rudy-os/issues).

## Install

Download the `.dmg` from the
[latest release](https://github.com/rudydoes/rudy-os/releases/latest), open it,
drag Rudy OS to Applications. The app updates itself from this repository.

## Privacy

Everything runs locally on your machine: your agents, your keys, your data.
