# Tilesets (not included)

The three office tilesets (`interiors.png`, `office-tileset.png`,
`a5-office-floors-walls.png`) are **Modern Interiors - RPG Tileset [16X16]** by
[LimeZu](https://limezu.itch.io/moderninteriors), used in official builds under
the Complete Version licence. That licence does not permit redistributing the
asset pack, so the images are not in this repository.

A from-source build runs fine but renders the office scene without its tileset
art. To get the art, purchase the pack from LimeZu and drop the three files in
this folder. See `../ATTRIBUTION.md` and `LIMEZUASSETS-LICENSE.txt`.
