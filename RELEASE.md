# Rudy OS v0.5.0

**A local hive of Claude Code, Antigravity, Codex, Gemini, Cursor, Grok & Copilot agents that run themselves.**
Messaging, routing, and remembering, coordinated by Rudy, who you talk to. Local-first: everything runs on your machine.

### → [**rudydoes.com**](https://rudydoes.com/) · see it in action, then grab a build below

---

## What's new in 0.5.0

**The first release under the Rudy OS name.** The rename goes all the way down: identity, cast, onboarding, site and on-disk namespaces.

- **New identity.** RUDY set in the pixel wordmark, OS in the brand accent. White on dark, ink on light. Rudy's own head is the icon.
- **New palette and new onboarding.** Five fixed-size steps in Rudy's own voice: pick my brain, where I work, my desk, house rules, review.
- **New cast.** Fifteen hires with their own names, portraits and break room banter.
- **New home.** [rudydoes.com](https://rudydoes.com/).
- Deep links, MCP server ids, hook groups and the hive bridge all live on the `rudy` namespace now.
